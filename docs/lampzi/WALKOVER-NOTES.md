# Lampzi website walkover (40 s, 1920x1080, 60 fps)

Composition `LampziWalk` (src/compositions/Lampzi/walk). Source: user screen recording `ds.mp4` (36.6 s, 1280x706). The recording was analysed for order and content; its footage is NOT reused (low resolution, the capture tool's own zoom effects and desktop wallpaper at the edges). Every page is rebuilt crisply, using the user's supplied site screenshots for Home, Templates (first row thumbnails) and the Job Tracker.

## Sound
Original calm synth bed + the supplied SaaS SFX Pack (click on every press, whooshes on page changes, riser into the brand reveal, soft ticks while typing). About -14 LUFS.
