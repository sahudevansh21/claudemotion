# When the redemption window is shut

A NAV is only useful if you can redeem at it.

BUIDL, the BlackRock USD Institutional Digital Liquidity Fund, is **Redemption closed** on Ethereum and Arbitrum. The fund redemption window is shut, so collateral cannot be redeemed at published NAV. The window opens in 6h. The published NAV may be fresh and perfectly correct, and that still doesn't help if you need to redeem before the window opens.

Compare USTB, the Superstate Short Duration US Gov Securities Fund, on Ethereum. It is **Open**: redemptions open, NAV fresh, onchain state matches issuer. The next NAV strike is in 13h.

For anyone using these as collateral, the question isn't only "what is the NAV?" but "can I redeem at it right now?" Those are two separate checks, and a NAV or price feed answers only the first one.

Oryn answers the second. One verdict per token, per chain, with the reason beside it: Redemption closed for BUIDL, Open for USTB. You see the window, not just the number.
